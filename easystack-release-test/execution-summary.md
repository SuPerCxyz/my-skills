# Execution Summary 测试计划执行汇总

每个测试计划执行时都必须维护一份执行汇总，**即使部分用例被用户明确要求不执行**。
汇总随执行进度持续更新，最终形成完整交付记录。

## 1. 适用范围

- 一个 MeterSphere 测试计划、一个本地测试计划或一次明确的批量执行任务。
- 包含全部用例, 状态包括通过、失败、阻塞、用例问题、跳过、执行中和未执行。
- 用户明确不执行的用例必须保留在汇总中，标记 `跳过` 并写明原因，不能从表中删除。

## 2. 文件位置与命名

- 计划根目录：`EXECUTION-SUMMARY.md`
- 可选机器可读状态：`execution-status.json`
- 结果写入 `pass/`、`fail/`、`blocked/` 或 `case-issues/` 下的 `<编号>-<用例名称>/`。
- `resultDir` 填实际相对路径, 例如 `pass/101664-直接创建空加密云硬盘/`。跳过和未执行
  用例在汇总写明原因, 结果目录列填 `—`。

## 3. 必填内容

1. 计划名称、计划 ID、用例来源、待测版本、目标环境和本轮变更范围。
2. 最近更新时间
3. 用例总数
4. 状态统计：通过 / 失败 / 阻塞 / 用例问题 / 跳过 / 执行中 / 未执行
5. 逐用例表：编号、用例名称、等级、状态、结果目录、资源名称/ID、说明
6. 阻塞与未执行说明
7. 更新记录及复测与原报告的关联。
8. 变更与用例的覆盖关系、未覆盖原因, 以及按已有项目准出条件确定的阻断项。

## 4. 状态定义

| 状态 | 含义 |
|---|---|
| 通过 | 用例步骤全部完成且符合预期 |
| 失败 | 执行完成但结果不符合预期 |
| 阻塞 | 环境/依赖/权限不满足，无法得出产品结论 |
| 用例问题 | 用例本身有问题（预期/参数/内容/产品不要求），不判产品通过或失败 |
| 跳过 | 用户明确不执行或适用长耗时跳过规则 |
| 执行中 | 已分派/正在执行，尚无最终结论 |
| 未执行 | 尚未开始，等待排期或授权 |

## 5. 更新规则

- 初始化：执行开始前先建立汇总，全部用例初始为 `未执行` 或 `跳过`。
- 增量更新：每完成一个用例、一个批次或收到子 Agent 汇总后立即更新。
- 按实际进展和结论更新用例状态, 保留全部用例行。
- 状态变化时同步移动用例目录到对应结论目录（`pass`/`fail`/`blocked`/`case-issues`），并更新 `resultDir`。
- 用户新增跳过要求时，将对应用例改为 `跳过` 并写明原因。
- 最终版：即使存在跳过/阻塞用例，也要输出完整汇总，并注明覆盖率与未执行原因。
- 时间戳：每次更新修改“最近更新时间”，并在更新记录追加一条。

## 6. 模板

```md
# <计划名称> 执行汇总

- 计划：<计划名称>（`<计划ID>`）
- 来源: <计划或本地用例>
- 待测版本与目标环境: <版本/环境>
- 变更范围: <本轮已确认范围>
- 最近更新：<YYYY-MM-DD HH:MM>
- 用例总数：<N>
- 状态统计: 通过 <N> / 失败 <N> / 阻塞 <N> / 用例问题 <N> / 跳过 <N> / 执行中 <N> / 未执行 <N>

## 用例状态

| 编号 | 用例名称 | 等级 | 状态 | 结果目录 | 资源名称/ID | 说明 |
|---|---|---|---|---|---|---|
| 101664 | 直接创建空加密云硬盘 | P1 | 通过 | pass/101664-... | <name>(<id>) | — |
| 101655 | 对接第三方商存创建加密类型 | P1 | 跳过 | — | — | 用户要求：无商业存储后端 |

## 阻塞与未执行说明

- ...

## 覆盖、阻断项与复测

- <变更或风险> | <对应编号与状态> | <证据或未覆盖、阻塞原因>
- <复测编号和运行> | <原报告与证据> | <复测报告与结论>

## 更新记录

- <YYYY-MM-DD HH:MM>: 初始化或更新说明
```

## 7. 与其他文档的关系

- 用例范围与跳过原因：`CASE-SCOPE-*.md`
- 单用例报告和证据见 [报告与证据格式](execution.md#evidence-policy-证据规范)
- MeterSphere 回填：结果与 comment 同批次提交
